Format for each code

## Sales Code

Example:
SIF_0001_0826

0001 - First Sale on that Date
08 - month
26 - last two digits of year

## Debt Code
 
 Example:
SIFD_0001_0826

0001 - First Sale on that Date
08 - month
26 - last two digits of year

## Customer Code

SIFC_0001

## Employee ID

SIFE_0001

## Trip ID

SIFT_0001_0826

0001 - First Trip on that Date
08 - month
26 - last two digits of year
